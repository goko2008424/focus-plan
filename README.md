# 专注计划 · 学习会计系统

> 系统是账本，你是会计。你定规则，它算账。

一个完全由用户自己定义规则的个人学习管理系统。

## ✨ 功能

| 模块 | 说明 |
|---|---|
| 🌟 任务管理 | 三栏任务：✅必须完成 / ⭐理想（选做，得积分）/ 🌱长期拓展（得积分），提前一天填写，支持换行批量添加 |
| ⏱ 正向计时 | 每次开始计时前填写「预计完成内容 + 预计用时」，完成后对比预计 vs 实际；暂停不计入用时 |
| 🎉 奖惩机制 | 必须任务全部完成 → 保底奖励弹窗（只加积分，数值可临时改，可"重新选择"）；三类全完成 → 完美额外奖励 |
| ⭐ 积分消费 | 理想/拓展任务赚积分，兑换表（多少分换什么）由用户自定义，兑换即扣积分，全程记流水账 |
| 📅 时间轴 | 柳比歇夫式 24 小时时间轴：点击空白 / 拖动选择 / 任务计时自动生成记录；分类（学习/拓展/辅助/生活/其他）、关联任务、计入学习标记、编辑/删除/复制到今日 |
| 📊 历史统计 | 按日记录、积分流水账、本周柱状图、本月学习趋势折线图 |
| ⚙️ 全自定义 | 时段、奖励数值、积分定价、拓展追加开关、顺延开关，全部自己定 |
| 💾 数据安全 | localStorage + IndexedDB 双备份，一键导出 .json/.csv、导入恢复，数据只存本机浏览器 |

## 🚀 本地使用

直接双击 `index.html` 即可在浏览器中使用（数据存入本地浏览器）。

## 🌐 部署分享（发链接给别人就能用）

本项目是零依赖纯静态站，任何静态托管都可用：

### GitHub Pages（推荐）
1. 新建仓库，把 `focus-plan/` 内文件推上去
2. 仓库 Settings → Pages → Source 选分支，保存
3. 访问 `https://你的用户名.github.io/仓库名/`，分享这个链接即可

### Cloudflare Pages（免 GitHub）
1. 打开 [pages.cloudflare.com](https://pages.cloudflare.com) → Create project
2. 拖入 `focus-plan/` 文件夹 → 部署
3. 打开 `https://你的项目名.pages.dev/` 分享

### Netlify / Vercel
- Netlify：`app.netlify.com/drop` 直接拖文件夹
- Vercel：`vercel.com` → New Project → 导入文件夹

> 提示：分享后每个使用者看到的是自己浏览器里的独立数据，互不影响。

## 📂 目录结构

```
focus-plan/
├── index.html          # 单页入口
├── manifest.webmanifest # PWA 清单（可添加到手机主屏幕）
├── sw.js               # Service Worker（离线缓存）
├── icon.svg            # 应用图标
├── css/style.css       # 全部样式
└── js/
    ├── store.js        # 数据层：模型/双备份存储/账本/导入导出
    ├── ui.js           # 弹窗/Toast/浮动动画/SVG 图表
    ├── tasks.js        # 任务模块 + 计时器 + 奖惩弹窗
    ├── timeline.js     # 时间轴模块
    ├── stats.js        # 历史统计模块
    ├── settings.js     # 设置 + 兑换表
    └── app.js          # 启动/路由/统计条
```

## 🗓 使用流程

前一天晚上填任务（「任务」页切到「明天」）→ 当天按任务 ▶ 开始计时 → 填预计内容/用时 → 完成对比确认 → 打勾 → 赚积分 / 触发奖励 → 每天点「结束今天」，未完成任务勾选顺延到明天 → 时间轴自动记录一切
